# APIannons

## What is this project?

This is a small API for classified ads. I made it to practise how an API can let a user read, add, change, and delete data. The ads are saved in a SQL Server database, and each ad belongs to a category.

I used ASP.NET Core for the API and Entity Framework Core to work with the database using C# classes. The API uses HTTP methods to say what should happen to the data.

## What do I need?

- .NET 10 SDK
- SQL Server

The connection string is in `APIannons/appsettings.json`. It currently expects SQL Server to be available as `localhost` and uses Windows authentication. If your SQL Server has a different name, change the `Server` value in the connection string.

When the application starts, it applies the database migrations and adds example categories and an ad if those tables are empty.

## The ad endpoints

All the ad routes start with `/api/Ad`.

| HTTP method | Route | What it does |
| --- | --- | --- |
| GET | `/api/Ad` | Gets all ads |
| GET | `/api/Ad/{id}` | Gets one ad by its ID |
| POST | `/api/Ad` | Creates a new ad |
| PUT | `/api/Ad/{id}` | Updates an existing ad |
| DELETE | `/api/Ad/{id}` | Deletes an ad |

For example, `GET https://localhost:7233/api/Ad/4` asks for the ad with ID 4. The ID must exist in the database. I should use the IDs returned by the API, because they are generated by the database.

## Creating an ad

For POST, I send the ad details as JSON. I do not send an ID because the database creates it. The API sets the publication date too. The category ID must belong to a category that already exists.

```json
{
  "name": "Furniture sale",
  "description": "Furniture in good condition",
  "price": 100,
  "location": "Stockholm",
  "categoryId": 1
}
```

If the ad is created, the API returns `201 Created` and includes the new ad in the response.

## Updating an ad

For PUT, I put the ID of the ad in the URL. The JSON body contains the values I want to update. The ID in the URL chooses which ad to change.

```http
PUT /api/Ad/4
Content-Type: application/json

{
  "name": "Winter clothes",
  "description": "For sale",
  "price": 20,
  "location": "Gothenburg",
  "categoryId": 3
}
```

The ad ID and category ID must exist. If the update works, the API returns `200 OK` with the updated ad.

## Deleting an ad

For DELETE, I put the ad ID in the URL:

```http
DELETE /api/Ad/4
```

If the ad is deleted, the API returns `204 No Content`. If the ID does not exist, the API returns `404 Not Found`.

## What I learned

- A controller receives HTTP requests and returns HTTP responses.
- A route tells the API which method should handle a request.
- Entity Framework Core lets the app query and save database data through a `DbContext`.
- An ad has a `CategoryId` foreign key that connects it to a category.
- `async` database methods let the app wait for database work without blocking the request thread.
- Swagger helps me try the endpoints and see the request and response formats.
